## 7. Git 실습 미션 
- commit, branch, push, merge 흐름 익히기

1. dev 브랜치에서 파일 가져오기
- dev 브랜치로 이동
- 자기소개 파일을 내려받기 (pull)
목적 : 최신 작업 내용 가져오기

2. 자기소개 작성 & 개인 브랜치에 업로드
- 본인 이름 브랜치 생성
- 자기소개 내용 작성
- commit 후 push
목적 : 각자 독립된 브랜치에서 작업하는 방식 익히기

3. Staging 브랜치에 작업 합치기
- staging 브랜치 이동
- 각자 만든 브랜치들을 staging에 merge

한 명은 staging에 올리고, 
한 명은 staging2라는 브랜치를 만들어서 올려주세요

목적 : 여러 사람의 작업을 하나로 합치는 과정

4. Main 브랜치에 배포
- main 브랜치 이동
- staging 내용을 main에 merge

한 명은 main에 올리고, 
한 명은 main2라는 브랜치를 만들어서 올려주세요

목적 : 최종 결과를 배포(main) 브랜치에 반영

5. 어떻게 미션을 수행했는지, 명령어 내용과 오류 사항이 있다면 정리해서 PDF!!!!!!!!로 공유
- 이름
- 일자
- 수행과정 내용 ( 어떤 순서로 진행했는지 )
- 결과 (스크린샷. github에 업로드 된 결과 )
- 느낀점 (어려웠던 점, 새롭게 알게 된 점)
